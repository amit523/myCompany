# FinAxis Technologies — Premium BFSI Website

A self-contained, multi-page static website for FinAxis Technologies Pvt Ltd.

## Pages
- `index.html` — homepage
- `solutions.html` — BFSI problem-solving approach
- `capabilities.html` — BRE, decisioning, workflow, integration and engineering capabilities
- `products.html` — product overview
- `products/incentivco.html` — Incentivco (Coming Soon)
- `products/vendoflow.html` — VendoFlow (Coming Soon)
- `industries.html` — Banking, NBFC, HFC and Insurance
- `about.html` — positioning, values and company story
- `contact.html` — demo contact form

## Visuals
All diagrams are local SVG files under `assets/images/`, so the project works offline after extraction.

## Open locally
Extract the ZIP and double-click `index.html`.
No Node.js, backend or database is required for this demo.

## Important before production
Replace the demo email address, add the real contact details, connect the contact form to a backend/service, add approved leadership bios, certifications and customer references only when they are verified, and have legal/security teams review final claims.

## Positioning
The website intentionally avoids fake client logos, fabricated metrics and unsupported claims. It emphasizes BFSI decisioning, Business Rule Engine expertise, workflow, integration and enterprise engineering.
